# Website Open Port Scanning and Security Analysis

> Work in progress. Full documentation will be added once scanning and analysis are complete.

## Overview

A defensive reconnaissance project: scan an **authorized** target with Nmap,
parse the results with Python, and analyze the security implications of each
open port.

**Windows** is used for development and GitHub management.
**Kali Linux** is used for Nmap scanning and running the analysis scripts.

## Ethical and Legal Disclaimer

Only scan systems you own or have explicit written permission to test.
This project performs reconnaissance and analysis only. It contains no
exploitation, brute-force, evasion, or denial-of-service functionality.
